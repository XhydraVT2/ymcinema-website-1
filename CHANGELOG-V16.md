# V16 — Soft cinematic ambient lighting

Based on YMCINEMA Premium V15, preserving its Bollywood-first genre filters and previous features.

- Replaced abrupt section/card palette switches with continuous frame-by-frame color interpolation (~1.5 second response).
- Reduced saturation and brightness of the preset ambient palettes.
- Reduced glow opacity, enlarged blur, and removed sharp hover-colored drop shadows.
- Preserved the existing unified background and hero transition.
- Honors reduced-motion preferences.

This is a code-level adjustment; visual browser verification and a production build are still recommended.
