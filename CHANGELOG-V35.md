# YMCINEMA V35 — SoundCloud Music Library
Based on V34 (no per-movie songs section).
- New /music page and navbar link.
- Bollywood, English, international, lo-fi, electronic, and instrumental discovery categories, opening SoundCloud search.
- Save public SoundCloud track or playlist URLs with validated oEmbed metadata.
- Personal collection persists in browser localStorage; filter and search saved items; remove items.
- Official SoundCloud iframe plays selected items without autoplay.
- No SoundCloud API credentials required. The library is user-curated, not an automatic SoundCloud catalog.
- No copyrighted music is hosted or downloaded by YMCINEMA.
