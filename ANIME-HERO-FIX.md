# Anime Hero: Recent Releases First

- Fixes the old 1997 Pokémon (and other classic franchises) being promoted as the first Anime highlight.
- The cinematic hero now selects Japanese-language animation that **premiered in the current or previous calendar year**, up to 8 entries.
- Uses TMDB popularity within each release year, mixes series and movies, and requires backdrop art.
- Older anime remain available in Popular, Top Rated, decade and Classic sections.
- The Trending Anime row now focuses on series debuting within the last three calendar years.
- The Home page, streaming manifests, player, and other navigation remain unchanged.

Note: TMDB series first-air dates describe the show's debut, not the release date of a newer season. This deliberately excludes decades-old franchises from the New Anime hero even if they still release episodes.

No environment variable changes required. Deploy the updated repository and check `/anime`.
