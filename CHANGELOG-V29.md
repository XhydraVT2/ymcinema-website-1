# V29 — Hero atmosphere and episode selection fix

- The global background now blends the current hero image with a muted, artwork-derived palette instead of section/hover-driven preset colors.
- Hero changes crossfade the ambient image; reduced-motion preferences are respected.
- Episode changes now synchronize player controls and URL; selecting an episode resets the player and highlights the correct episode.
- The watch player remounts on season/episode URL changes to prevent stale playback state.
- No new streaming providers or playback sources were added.
