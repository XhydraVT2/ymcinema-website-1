# YMCINEMA Premium V6 — Ambient Glass Update

Based on Premium V6 Movie Detail Rebuild, retaining its TV episodes, season selector, Watch 1–7, and Indian provider discovery.

- Removed the solid blue rounded container around TV episodes.
- Added full-bleed, softly layered blue-gray atmosphere behind the episode browser.
- Integrated the episodes area into the surrounding page instead of an isolated card.
- Applied translucent frosted-glass surfaces to season controls and detail panels.
- Retained responsive layouts and reduced-motion accessibility.

Note: The CSS uses modern `:has()` selectors supported by current major browsers. Playback and production build are not verified here.
